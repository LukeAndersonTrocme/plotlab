# About this manual {-}

[Download this manual as a PDF, to print or to read offline.](plotlab-manual-v0.1.pdf){.pdf-link}

plotlab turns an image into lines for a pen plotter, or into files for print or screen. It
runs in your browser at
[lukeandersontrocme.github.io/plotlab](https://lukeandersontrocme.github.io/plotlab/).
There is nothing to install.

This manual is for people who make images and have not used plotlab before. You don't need
to know anything about programming or plotters.

How it is laid out:

- **Parts 1 to 3** say what plotlab is, what's on the screen, and the few ideas it is built
  on. Read these first.
- **Part 4** is a ten-minute first drawing.
- **Part 5** has short how-tos, one per task. Use them in any order.
- **Part 6** is the reference: every step, preset, setting and file type.
- **Part 7** lists what this version can't do yet.

Words in **bold** are the labels you see on screen.

**Giving feedback.** Every section has a number, and every page of the PDF has a page
number. To point at something, give the manual's version and the section, for example
"v0.1, §5.6: I expected the inks to…". Then contact Luke. The project lives at
[github.com/LukeAndersonTrocme/plotlab](https://github.com/LukeAndersonTrocme/plotlab).

This manual changes with each release of plotlab. The version on the title page matches
the version of the app it describes. A PDF copy is at
[lukeandersontrocme.github.io/plotlab/manual/plotlab-manual-v0.1.pdf](https://lukeandersontrocme.github.io/plotlab/manual/plotlab-manual-v0.1.pdf).
