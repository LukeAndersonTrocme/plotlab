# Limits in v0.1, and what's planned

This is a first version. These are the limits we know about.

## Known limits

- **Browsers.** Most testing so far has been in Chrome on a laptop. Safari, Firefox and
  real phones have barely been tried.
- **The plotter is a stand-in.** The time estimate uses a generic A3 plotter with
  placeholder speeds, so treat the times as rough. **Send to plotter** saves a file; it
  doesn't talk to a machine.
- **Experimental presets are slow.** *Turing pattern*, *Stipple portrait* and
  *One-line stipple (TSP)* can take a while on big images.
- **Atkinson print can't be plotted yet.** Picking it switches the output to Print prep.
- **Work lives in one browser.** Projects are stored in the browser you made them in.
  Nothing syncs. A bundle is the only way to move a project.
- **The phone is for viewing.** It can open bundles, but not edit recipes.
- **English only.** A French version will come once the app settles.

## Planned

These are planned but not in this version:

- **Driving a plotter directly**, and real profiles for real machines.
- **Explore**: a button that tries random settings and shows a strip of variants to pick
  from.
- **Library**: a full-screen view of all your images and their checkpoints.
- **The history behind each step**: how engraving, halftone screens and process cameras did
  by hand what each step does. This is being written with Nicolas Oligny (bosny).
