# Appendix A. Glossary {-}

The words plotlab uses, in alphabetical order. The project's full list of terms is
[GLOSSARY.md](https://github.com/LukeAndersonTrocme/plotlab/blob/main/GLOSSARY.md) in the
repository.

| Word | Meaning |
|---|---|
| **Band** | The area between two levels of darkness, as a shape. Band 1 is the lightest |
| **Bundle** | A whole project packed into one .zip file (§3.8) |
| **Checkpoint** | A saved copy of your settings, with a picture, a name and a note (§3.4) |
| **CMYK** | Cyan, magenta, yellow and black: the four inks of colour printing |
| **Ink** | A layer's colour, width and mix (Multiply or Normal) |
| **Layer** | One map of where one ink goes |
| **Lane** | One ink's row of steps after a split, when the inks are Independent (§3.6) |
| **Levels** | How many shades of grey are kept. Two levels means black and white |
| **Linked / Independent** | Whether the four inks share one set of steps or each has its own (§3.6) |
| **Output target** | Where the work ends up: Plotter, Digital image, Digital vector or Print prep (§3.7) |
| **Pass** | Everything one pen draws before the next pen goes in |
| **Pen** | Plotter wording for an ink with a physical width |
| **Pin** | Keep a step's settings in the sidebar while you look at another step |
| **Plate** | One ink's file for print prep |
| **Preset** | A ready-made recipe (§3.3) |
| **Project** | One image with its recipe and checkpoints |
| **Proof** | A picture of how the plates will print together |
| **Recipe** | The ordered steps and all their settings (§3.1) |
| **Registration marks** | Marks on every plate or pass so the inks line up |
| **Seed** | A number that fixes a step's randomness, so you get the same result again |
| **Source** | Your image, the first box in the strip |
| **Stack** | Where the inks meet, in printing order (§3.6) |
| **Step** | One operation in the recipe, with its own settings (§3.2) |
| **Travel** | Moves the pen makes while lifted |

# Appendix B. The command line {-}

plotlab also runs from a terminal, for people who want to process many images or frames at
once with the same recipe. In the app, **Copy as CLI command** (Plot mode) gives the command
for what's on screen.

How to install and use it is in the
[README](https://github.com/LukeAndersonTrocme/plotlab#use-it) in the repository.
