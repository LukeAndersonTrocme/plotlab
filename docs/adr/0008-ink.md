# 8. Ink replaces pen in the model

Status: accepted (provisional, 2026-11-11)

## Decision
Each layer has an **ink**: colour, mix mode (multiply by default, normal as an option) and
width (used by plotter and vector targets). Previews and digital output composite inks with
the mix mode, so overlapping C/M/Y look like ink on paper. "Pen" remains the plotter-facing
word and appears in machine profiles and pen-change prompts.
